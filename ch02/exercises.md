# Basic Structures (Sets, Functions, ...)

## Exercises

Write programs with the specified output and input

1. Given subsets A and B of a set with n elements, use bit strings to find A', A ∪ B, 
   A ∩ B, A − B, and A ⊕ B.
2. Given multisets A and B from the same universal set, find A ∪ B, A ∩ B, A − B, 
   and A + B (see Section 2.2.5)
3. Given a function f from {1, 2, … ,n} to the set of integers, determine whether f is 
   one-to-one.
