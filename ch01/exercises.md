# CHAPTER 1 Exercices

## Elements and Sets

- List all subsets of the set {a, b, c} (There are 8 subsets, of which 7 are proper subsets, counting the null set).
- Use the definition of complement to prove that (X')' = X for any set X.
- How many different subsets are there for a set containing a finite number of n elements? [Hint: Express the number
of subsets with u elements, u <= n, as a combinatorial symbol and use the binomial theorem to sum from 0 to n]
